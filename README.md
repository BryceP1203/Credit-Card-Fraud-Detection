# Credit-Card-Fraud-Detection

This project uses machine learning to detect fraudulent credit card transactions. The notebook includes data preprocessing, model training, evaluation, and analysis of fraud detection performance.

## Tools Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Project Goal
The goal of this project is to classify credit card transactions as fraudulent or legitimate using machine learning techniques.
